## 免密码登陆

### 启用或停用 root 用户

1. 选取苹果菜单 () >“系统偏好设置”，然后点按“用户与群组”（或“帐户”）。
2. 点按 <img src="https://support.apple.com/library/content/dam/edam/applecare/images/en_US/il/elcapitan-lock-inline.png" alt="锁形图标" style="zoom:33%;" height="60" />，然后输入管理员名称和密码。
3. 点按“登录选项”。
4. 点按“加入”（或“编辑”）。
5. 点按“打开目录实用工具”。
6. 点按“目录实用工具”窗口中的 <img src="https://support.apple.com/library/content/dam/edam/applecare/images/en_US/il/elcapitan-lock-inline.png" alt="锁形图标" style="zoom:33%;" />，然后输入管理员名称和密码。
7. 从“目录实用工具”的菜单栏中：
   - 选取“编辑”>“启用 Root 用户”，然后输入要用于 root 用户的密码。
   - 或者选取“编辑”>“停用 Root 用户”。

### 以 root 用户身份登录

启用 root 用户后，仅在以 root 用户身份登录时，您才拥有 root 用户的权限。

1. 选取苹果菜单 >“退出登录”，以退出登录您的当前用户帐户。
2. 在登录窗口中，使用用户名“root”以及为 root 用户创建的密码登录。
   如果登录窗口显示用户列表，请点按“其他”，然后登录。

完成任务后，应务必停用 root 用户。 

### 更改 root 密码

1. 选取苹果菜单 () >“系统偏好设置”，然后点按“用户与群组”（或“帐户”）。
2. 点按 <img src="https://support.apple.com/library/content/dam/edam/applecare/images/en_US/il/elcapitan-lock-inline.png" alt="锁形图标" style="zoom:33%;" />，然后输入管理员名称和密码。
3. 点按“登录选项”。
4. 点按“加入”（或“编辑”）。
5. 点按“打开目录实用工具”。
6. 点按“目录实用工具”窗口中的 <img src="https://support.apple.com/library/content/dam/edam/applecare/images/en_US/il/elcapitan-lock-inline.png" alt="锁形图标" style="zoom:33%;" />，然后输入管理员名称和密码。
7. 从“目录实用工具”的菜单栏中，选取“编辑”>“更改 Root 密码…”
8. 在出现提示时输入 root 密码。

```
sudo chmod u-w /etc/sudoers
```

```
sudo vi /etc/sudoers
```

将 #%admin ALL=(ALL) ALL
替换为 %admin ALL=(ALL) NOPASSWD: ALL

## 免密码登陆阿里云服务器

通过ssh root@host连接阿里云服务器

```bash
ssh-keygen	##  一路回车
```


本地运行：

```bash
scp ~/.ssh/id_rsa.pub root@host:/root/ ## 将ssh公钥拷贝到服务器上
```

服务器上：

```bash
mv id_rsa.pub .ssh/yourname.pub
cd .ssh/
cat yourname.pub >>authorized_keys
```

将拷贝到服务器上的公钥**移动&重命名为.ssh/yourname.pub**，
