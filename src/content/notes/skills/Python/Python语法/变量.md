## collections

### collections.Counter()

https://docs.python.org/zh-cn/3/library/collections.html#collections.Counter

dict的子类，用于计数可哈希对象。
它是一个集合，元素像字典键(key)一样存储，它们的计数存储为值。

- 可哈希的数据类型

  即不可改变的数据结构: (字符串str、元组tuple、对象集objects)。 

##### 语法

```python
c = Counter()                         # a new, empty counter
c = Counter('gallahad')               # a new counter from an iterable
c = Counter({'red': 4, 'blue': 2})    # a new counter from a mapping
c = Counter(cats=4, dogs=8)           # a new counter from keyword args
```

设置一个计数为0不会从计数器中移去一个元素。使用 `del` 来删除它:

```python
>>> c['sausage'] = 0                        # counter entry with a zero count
>>> del c['sausage']  
```

##### 例：统计词频

```python
from collections import Counter
from typing import Mapping
colors = ['red', 'blue', 'red', 'green', 'blue', 'blue']
c =  Counter(colors) 
print (dict(c)) # {'red': 2, 'blue': 3, 'green': 1}
```

most_common、删除、相加减、最大最小值

```python
from collections import Counter
from typing import Mapping
colors = ['red', 'blue', 'red', 'green', 'blue', 'blue']
c =  Counter(colors) 

print (dict(c)) # {'red': 2, 'blue': 3, 'green': 1}
print (tuple(c))# ('red', 'blue', 'green')
print (list(c)) # ['red', 'blue', 'green']
print (list(c.elements())) # ['red', 'red', 'blue', 'blue', 'blue', 'green']
print (c.most_common(1))   # [('blue', 3)]
print (c.most_common(3))   # [('blue', 3), ('red', 2), ('green', 1)]

del c['red']
print(dict(c))  # {'blue': 3, 'green': 1}

c = Counter(a=3, b=1)
d = Counter(a=1, b=2)
print(c + d)                     # 相加
#Counter({'a': 4, 'b': 3})
print(c - d)                     # 相减，如果小于等于0，删去
#Counter({'a': 2})
print(c & d)                     # 求最小
#Counter({'a': 1, 'b': 1})
print(c | d)                     # 求最大
#Counter({'a': 3, 'b': 2})
```

### [collections.defaultdict()](https://blog.csdn.net/yangsong95/article/details/82319675)

通过Key访问字典，当Key不存在时，会引发‘KeyError’异常。为了避免这种情况的发生，可以使用collections类中的defaultdict()方法来为字典提供默认值。

语法：`collections.defaultdict([default_factory[, …]])`

`.items()`	`.append`

```python
from collections import defaultdict
s=[('yellow',1),('blue', 2), ('yellow', 3), ('blue', 4), ('red', 1)]
d=defaultdict(list)
print(d)    						# defaultdict(<class 'list'>, {})
for k, v in s:
    d[k].append(v)
print(d.items()) 				# dict_items([('yellow', [1, 3]), ('blue', [2, 4]), ('red', [1])])
print(sorted(d.items()))# [('blue', [2, 4]), ('red', [1]), ('yellow', [1, 3])]
print(d)   # defaultdict(<class 'list'>, {'yellow': [1, 3], 'blue': [2, 4], 'red': [1]})
```

defaultdict还可以被用来计数，将default_factory设为int即可，counter更方便

```python
from collections import defaultdict
s = 'mississippi'
d = defaultdict(int)
for k in s:
    d[k] += 1
print(d)   # defaultdict(<class 'int'>, {'m': 1, 'i': 4, 's': 4, 'p': 2})
print(d.items())   # [('i', 4), ('m', 1), ('p', 2), ('s', 4)]
```

## 集合	{10, 20, 30, 40, 50}

```python
s1 = {10, 20, 30, 40, 50}
s2 = set('abcdefg')
s3 = {}
print(type(s1))  # set
print(type(s2))  # set
print(type(s3))  # dict
```

1. 集合可以去掉重复数据；
2. 集合数据是无序的，故不支持下标



``` python
s1 = {10, 20}
s1.add(100) # 增加数据    add()
s1.add(10) # 因为集合有去重功能，追加的当前集合已有数据的话，则不进行任何操作
print(s1)  # {100, 10, 20}

s1 = {10, 20}
s1.update(100)  # 报错
s1.update([100, 200])# update(), 追加的数据是序列。
s1.update('abc')
print(s1)	# {'b', 100, 200, 10, 'c', 'a', 20}

s1.remove(10) # 删除集合中的指定数据，如果数据不存在则报错。
s1.discard(10)# 删除集合中的指定数据，如果数据不存在也不报错。
del_num = s1.pop() # 随机删除集合中的某个数据，并返回这个数据。

print(10 in s1) # False
print(10 not in s1) # True
```
