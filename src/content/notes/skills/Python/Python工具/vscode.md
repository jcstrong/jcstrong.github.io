# vscode设置

## import包报错

在CMD中得到python的路径

```
C:\Users\jcstr>where python
C:\Users\jcstr\AppData\Local\Microsoft\WindowsApps\python.exe
```

打开这个路径使用pip安装

```
pip install 没有的那个包名
```

## vscode链接树莓派远程调试
