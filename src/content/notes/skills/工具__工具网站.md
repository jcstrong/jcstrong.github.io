```

```

## 模糊检索	通配符？、*

```
龙? 凤?
Halley's comet appears every * years
```

截词符号有星号*、?、%、$等

```
*chemi* 	前后截断
rac??et 	中截断
```

## 与	空格

增加限制条件

## 或	｜或 OR

扩大检索范围

## 非	- 或 NOT

前一个检索词的结果中排除后一个词

## 优先顺序: NOT>AND>OR

## filetype语法

对二进制文件的搜索(pdf、 ppt、 xls、 doc、 jpg、rtf、all）

```
西南交通工作方案 filetype:doc
filetype:pdf 高速铁路 (综述|进展)
```

## intitle、intext、allintitle、allintext语法

搜索标题或搜索正文

```
钟南山 intitle:专访
intitle:娱乐
intext:"N95"+"importer"
```

行业、产品常用 +importer、 +buyer、+邮箱后缀

## inurl

```
inurl:mp3      		 		找MP3
inurl:wanganyi    		找人 (如: 王安忆)
inurl:shendiaoxialv 	找书 (如: 神雕侠侣)
inurl:forum.php 			找论坛
inurl:download   			找软件
Inurl:rar        			找压缩包
```
