#### 查看权限

```
[root@localhost test]# ll file1.txt 
-rw-rw-r--. 1 it it 0 2月   8 06:06 file1.txt
```

文件类型-访问权限	属主 属组  

访问权限 共10位

1:文件类型	2～4：文件所有者权限	5～7：文件所属组的权限	8～10：其他用户权限

##### 文件类型

| -    | 常规文件                                  |
| ---- | ----------------------------------------- |
| d    | 目录文件                                  |
| b    | block device块设备文件                    |
| c    | character device 字符设备文件             |
| l    | symbolic link 符号链接文件即软链接文件    |
| p    | pipe 命名管道文件                         |
| s    | socket 套接四文件用于实现两个进程进行通信 |

##### 文件权限

| 权限项   | 读   | 写   | 执行 |
| -------- | ---- | ---- | ---- |
| 字符表示 | r    | w    | x    |
| 数字表示 | 4    | 2    | 1    |

##### 常见权限数字表示

```php
-rw------- (600)      只有拥有者有读写权限。
-rw-r--r-- (644)      只有拥有者有读写权限；而属组用户和其他用户只有读权限。
-rwx------ (700)     只有拥有者有读、写、执行权限。
-rwxr-xr-x (755)    拥有者有读、写、执行权限；而属组用户和其他用户只有读、执行权限。
-rwx--x--x (711)    拥有者有读、写、执行权限；而属组用户和其他用户只有执行权限。
-rw-rw-rw- (666)   所有用户都有文件读、写权限。
-rwxrwxrwx (777)  所有用户都有读、写、执行权限。
```
1 4 5 6 7

用二进制表示

    r-- = 100
    -w- = 010
    --x = 001
    --- = 000
转化成八进制

    rwx = 111 = 7
    rw- = 110 = 6
    r-x = 101 = 5
    r-- = 100 = 4
    -wx = 011 = 3
    -w- = 010 = 2
    --x = 001 = 1
    --- = 000 = 0
