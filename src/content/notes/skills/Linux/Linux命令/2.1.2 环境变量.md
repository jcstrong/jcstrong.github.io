#### 配置文件

/etc/profile	系统全局配置文件

/.bash_profile	属于用户配置文件，用于设定用户的环境变量

/.bashrc	专属的配置信息

环境变量更改后，在用户下次登陆时生效。如果想立刻生效，则可使用`source`读入配置文件 

```# source .bash_profile```

#### 常用环境变量

PATH	决定了shell将到哪些目录中寻找命令或程序 

​	在主目录下的``.profile``或``.bashrc``文件中，系统目录下的profile文件慎重修改

​	PATH声明格式

  				`PATH=$PATH:<PATH 1>:<PATH 2>:<PATH 3>:------:<PATH N>`

​	将PATH临时加入当前目录，若要永久则需要将下列命令加入``.bashrc``尾部，再用source命令使其生效

​					`export PATH=$PATH:<PATH 1>:<PATH 2>:<PATH 3>:------:<PATH N>`

​	查看当前PATH

​				``echo $PATH``

HOME	当前用户主目录

HISTSIZE	历史记录数

LOGNAME	当前用户登录名

HOSTNAME	指主机的名称

SHELL 	当前用户Shell类型

LANG	语言相关的环境变量，多语言可以修改此环境变量

MAIL	当前用户的邮件存放目录

USER	查看当前用户

LOGNAME	当前用户登录名

PWD	当前目录绝对路径名

#### 环境变量设置

##### export修改环境变量

​	 使用命令echo显示环境变量 

​	``echo $HOME``

​	修改环境变量MYNAME	
 	``export MYNAME=”my name is pingzhenyu”``

​	 ``export $ MYNAME``

##### 使用env命令显示所有的环境变量

​	使用grep进行筛选		``env | grep -i "PATH"``

##### 使用set命令显示所有本地定义的Shell变量

​	使用grep进行筛选		``set | grep -i "PATH"``	

##### 使用`unset（选项）（参数）`命令来清除环境变量

​	-f	仅删除函数

​	-v	仅删除变量

##### 使用`readonly（选项）（参数）`命令设置只读变量

​	-f	定义只读函数

​	-a	定一只读数组变量

​	-p	显示系统中 全部只读变量列表

通过修改环境变量定义文件来修改环境变量
