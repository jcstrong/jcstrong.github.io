# touch命令

新建空文件

更新现有文件的时间戳、访问权限和修改时间

touch（选项）（参数）

### 创建空文件、创建5个.txt文件

#### 命令：touch file{1..5}.txt

```
[it@localhost test]$ ls
[it@localhost test]$ touch log
[it@localhost test]$ ls
log
```

```
[it@localhost test]$ touch file{1..5}.txt
[it@localhost test]$ ls
file1.txt  file2.txt  file3.txt  file4.txt  file5.txt  log
```

# file 命令

格式：`file [OPTION]...FILE...`

### 显示文件类型

```
[root@localhost test]# ls
file1.txt  file2.txt  file3.txt  file4.txt  file5.txt  log
[root@localhost test]# file file2.txt 
file2.txt: empty
```
