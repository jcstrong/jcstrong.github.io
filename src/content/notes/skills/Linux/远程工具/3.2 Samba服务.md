#### windows访问linux的共享目录

**ftp**

基于tcp/ip，跨平台性强

ftp文件传输时，不能直接修改主机上的文件

**nfs**

相当于挂在了一个文件系统，可以修改主机上的文件

只能在unix系列的主机上互相分享

#### SAMBA

跨平台、可直接 修改主机

##### SMB协议（server message block）

模仿的是windows内核的文件和打印共享协议

是c/s架构的协议

##### 主要功能

访问权限、客户功能、解析NetBios、命令行工具

##### 工作原理

客户端向samba发起请求

samba接到请求查询smb.conf文件，看共享目录是否存在以及来访者是否有权限

samba将访问过程的系统信息和用户行为存放到日志

##### 三个主要套件

samba软件提供SMB服务器各项服务程序

- nmbd、smbd是Samba的核心守护进程，在服务器启动到停止期间持续运行。
  - smbd监听139TCP端口
    - smbd提供两种模式：共享模式、用户模式。用户模式为每个用户设置用户吗和密码，可以设置不同的访问权限
    - 开放139、445端口
  - nmbd负责监听137TCP端口和137UDP端口
    - 名字解析
      - 广播与点对点

samba-common

samba-client

###### 设置Samba的配置文件smb.conf 配置

由全局配置、共享配置两部分组成

应将``[homes]``段取消注释，因为访问linux时要使用用户进行登录，需要访问到home目录

```
vi /etc/samba/smb.conf
```

完成修改后进行检查

```
testparm /etc/samba/smb.conf
```

重启服务

```
service smbd restart
```

**Global Settings**

针对所有共享资源的默认配置

**在[global]段完成:**

workgroup = Linuxgrp 	(设置工作组的名称)

server string = IOT	(服务器注释设置为你的班级)

Netbios name = jc 	(主机名称设置为你的姓名拼音)

Security = share	(设置服务器允许匿名访问共享资源)



**Share Definitions**

针对当前共享目录的设置

**[share]段添加**

```
[ro-samba]	
	comment = read only share
#指定共享目录
	path = /home/ro-samba
#是否支持访客登陆/允许匿名用户访问该目录
	guest ok = yes
;	public = yes
#只读/不可写
	browseable = yes
; writeable = no
	read only =yes
	
[rw-samba]	
	comment = write able share
	path = /home/rw-samba
#是否支持访客登陆
	guest ok = yes
;	public = yes
#只读/不可写
	browseable = yes
; writeable = yes
	write list = root
```

#### samba共享进阶练习

建立共享目录share ，该目录拒绝其他用户访问，仅允许samba组中的用户访问。

samba中有三个用户 : root、smbuser、smbguest。

这三个用户对share的权限也不同 : root只读 ; smbuser可读写、smbguest拒绝访问。

```
mkdir share
chmod 777 share
useradd smbguest
passwd smbguest
smbpasswd -a smbguest
groupadd samba
gpasswd -a root samba
gpasswd -a sumbuser samba
gpasswd -a smbguest samba
vi /etc/samba/smb.conf
```

在smb .conf文件中添加新的共享

```
[share]	
	comment = write able share
	path = /home/share

  writeable = no
	write list = smbuser
# ‘@’表示这是一个组名，下面这条语句表示将samba整组加入可访问的用户	
	valid users = @samba
	invalid users = smbguest

：wq
```

重启smbd
